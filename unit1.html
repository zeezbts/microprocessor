Microprocessor-Initiated Operations

Microprocessor-initiated operations are the fundamental data transfer and control actions that the microprocessor (MPU) performs to interact with memory or peripheral devices, primarily including memory read/write and I/O read/write. These operations are managed through the system bus (address, data, control) and involve identification of the target, synchronization, and data transfer.

Primary Operations List

  • Memory Read
  • Memory Write
  • I/O Read (Input)
  • I/O Write (Output)

Key Microprocessor-Initiated Operations (8085 Example)

  • Memory Read: The MPU retrieves data or instructions from a specific memory location.
  • Memory Write: The MPU sends data to a specific memory location for storage.
  • I/O Read (Input): The MPU reads data from an external input device (e.g., keyboard).
  • I/O Write (Output): The MPU sends data to an external output device (e.g., LED display).

Steps in MPU Initiated Operations

  1. Identify peripheral/memory: The MPU places the 16-bit address on the address bus to locate the device.
  2. Timing/Synchronization: The MPU sends control signals (like RD or WR) to synchronize with the device.
  3. Data Transfer: Data is transferred via the data bus.

Distinction from Externally Initiated Operations

While the above are initiated by the processor to control the system, externally initiated operations allow external devices to interrupt or manage the MPU, including:

  • Reset: Suspends operation and clears the Program Counter.
  • Interrupt: External signal forcing the MPU to execute a service routine.
  • Ready: Synchronizes slow peripherals with the faster MPU.
  • Hold: Requests control of the system bus (DMA).

Bus organization of 8085 microprocessor

Introduction

    The 8085 microprocessor uses a 16-bit address bus, an 8-bit bidirectional data bus, and a control bus to manage data flow and peripheral communication. A key feature is the multiplexed (AD0-AD7) lines, which carry lower-order address bits and data at different times, requiring an external latch (via ALE signal) to separate them

    Core Bus Components:

    Address Bus ( A8-A15 & AD0-AD7):
  • A 16-bit, unidirectional bus (CPU to memory/IO) that can address up to 216=65,536locations (64 KB).
    • Data Bus ( AD0-AD7 ):
  • An 8-bit, bidirectional bus used for transferring data between the microprocessor, memory, and I/O devices.
    • Control Bus:
  • A set of signal lines that carry control signals to regulate timing and operations, including Read (RD), Write (WR), and Address Latch Enable (ALE).

    • Multiplexed Bus Organization

  • The 8085 uses multiplexed address/data lines (AD0 -AD7 ) to reduce pin count.
    • Address Phase:
  • During the first clock cycle of a machine cycle, AD0 -AD7carry the lower-order byte of the address.
    • Latch Activation:
  • The ALE (Address Latch Enable) signal goes high, causing an external latch to store the lower-order address.
    • Data Phase:
  • In subsequent cycles, AD0 -AD7 act as a bidirectional data bus to transfer data.

    • Key Signal Roles

    ALE (Address Latch Enable):
  • Indicates that the AD0 -AD7 lines hold address information.
    • RD(Read):
  • Signal to instruct memory or I/O device to read data.
    • WR(Write):
  • Signal to instruct memory or I/O device to accept data.
8085 Microprocessor Flag Register

8085 Microprocessor Flag Register

The 8085 Flag Register is a special-purpose 8-bit register containing 5 active status bits (flip-flops) and 3 unused/indeterminate bits.

The Arithmetic Logic Unit (ALU) updates these bits automatically after executing arithmetic or logical operations to reflect the characteristics of the resulting data.

🗺️ Bit Positioning Map

The 8 bits of the Flag register are organized in the following fixed layout configuration:

Bit Position D7 D6 D5 D4 D3 D2 D1 D0
Flag Name S Z X AC X P X CY
  • Active Status Flags: S (Sign), Z (Zero), AC (Auxiliary Carry), P (Parity), CY (Carry)
  • Unused Bits (X): D5, D3, and D1 are undefined/don't-care bits.

⚙️ Breakdown of the 5 Status Flags

  • Sign Flag (S - Bit 7)

    Set to 1 if the most significant bit (D7) of the result is 1, indicating a negative number. Reset to 0 if D7 is 0, indicating a positive number.

  • Zero Flag (Z - Bit 6)

    Set to 1 if the ALU operation results in an output value of exactly zero. Reset to 0 if the resulting output is non-zero.

  • Auxiliary Carry Flag (AC - Bit 4)

    Set to 1 if a carry out is generated from lower-nibble bit D3 to bit D4 during an addition.

  • Parity Flag (P - Bit 2)

    Set to 1 if the 8-bit result contains an even number of 1s (Even Parity). Reset to 0 if the result contains an odd number of 1s (Odd Parity).

  • Carry Flag (CY - Bit 0)

    Set to 1 if an addition generates a carry out of the most significant bit (D7), or if a subtraction requires a borrow. Reset to 0 when no carry or borrow happens.

Intel 8085 Microprocessor Internal Data Operations

Intel 8085 Microprocessor Internal Data Operations

In the Intel 8085 microprocessor, internal data operations are executions that occur entirely within the chip's internal structure. They do not utilize the external system bus to read from or write to external memory or I/O devices after the instruction has been fetched.

These operations are performed at high speed by the Arithmetic Logic Unit (ALU) using the internal registers and the accumulator.

⚙️ Core 8085 Internal Data Operations

The 8085 MPU performs four primary classifications of internal data operations:

  • Store 8-bit Data

    Loading an immediate 8-bit value directly into an internal register or register pair (e.g., MVI B, 32H).

  • Data Transfer

    Copying data from one internal register to another (e.g., MOV A, B). The source register contents remain unchanged.

  • Arithmetic Operations

    Performing mathematics like addition, subtraction, increment (INR), or decrement (DCR) on data inside the registers.

  • Logical Operations

    Executing bitwise computations like AND, OR, XOR, complementing (CMA), or rotating bits (RLC, RRC) within the Accumulator.

8085 Microprocessor Externally Initiated Operations

8085 Microprocessor Externally Initiated Operations

Externally initiated operations (or peripheral-initiated operations) are actions that are not triggered by the microprocessor itself, but rather by external devices or peripherals. These devices send signals to the 8085 MPU via specific pins to interrupt its current execution, request control of the system buses, or synchronize data transfers.

The Intel 8085 microprocessor supports four primary externally initiated operations.

⚙️ Core 8085 Externally Initiated Operations

  • Reset: When an external signal is applied to the RESET IN pin, the MPU drops all current operations, clears the internal Program Counter (PC) to 0000H, resets the interrupt enable flip-flops, and forces the system to restart initialization.
  • Interrupt: An external peripheral sends a signal via hardware interrupt pins (TRAP, RST 7.5, RST 6.5, RST 5.5, or INTR) to pause the MPU's current program execution. The MPU completes its current instruction, stores the PC on the stack, and branches out to execute a specific Interrupt Service Routine (ISR).
  • Ready: Slow peripheral devices or memory chips utilize the READY pin to communicate with the faster MPU. Dropping this line introduces "Wait States" inside the MPU machine cycles until the slower device is prepared for an accurate data transfer.
  • Hold: An external device (such as a Direct Memory Access or DMA Controller) sends a signal to the HOLD pin requesting complete control over the system buses. The MPU completes its current operations, places its address, data, and control lines into a high-impedance state (tri-state), and confirms the release via the HLDA (Hold Acknowledge) pin.
