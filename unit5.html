8051 Timer & Counter Operating Modes

The 8051 microcontroller features two internal timers, Timer 0 and Timer 1. The TMOD (Timer Mode) register configures their behavior using two specific bits: M1 and M0.

Mode 0: 13-Bit Timer/Counter (M1=0, M0=0)

This mode acts as a legacy configuration for older systems.

  • Uses 5 bits of the TL register.
  • Uses 8 bits of the TH register.
  • Counts up to a maximum of 8,191.
  • Triggers an overflow flag at maximum count.
  • Maintains backward compatibility with the 8048 chip.

Mode 1: 16-Bit Timer/Counter (M1=0, M0=1)

This is the most common configuration for generating custom time delays.

  • Utilizes full 16-bit capacity.
  • Combines both TL and TH registers.
  • Counts up to a maximum of 65,535.
  • Requires manual register reloading after overflow.
  • Generates long, precise time delay intervals.

Mode 2: 8-Bit Auto-Reload (M1=1, M0=0)

This mode automatically resets itself, making it highly efficient for continuous loops.

  • Functions strictly as an 8-bit counter.
  • Holds the active count inside TL.
  • Stores the reset value inside TH.
  • Overflow copies TH back into TL automatically.
  • Eliminates software reloading overhead entirely.
  • Serves as the primary baud-rate generator.

Mode 3: Split Timer Mode (M1=1, M0=1)

This configuration splits the hardware to gain an extra timer.

  • Affects Timer 0 only.
  • Divides Timer 0 into two 8-bit blocks.
  • Turns TL0 into a standard 8-bit timer.
  • Turns TH0 into a second 8-bit timer.
  • Commandeers Timer 1 control bits for TH0.
  • Restricts Timer 1 to background baud-rate tasks.
8051 Microcontroller Interrupts

8051 Microcontroller Interrupts

The 8051 microcontroller contains five standard interrupt sources.

The Five 8051 Interrupts

External Interrupt 0 (INT0)

  • Pin P3.2 receives the signal.
  • Vector address is 0003H.
  • Highest default hardware priority.
  • Detects low levels or falling edges.

Timer 0 Interrupt (TF0)

  • Triggered by Timer 0 overflow.
  • Vector address is 000BH.
  • Second highest hardware priority.
  • Clears TF0 flag automatically.

External Interrupt 1 (INT1)

  • Pin P3.3 receives the signal.
  • Vector address is 0013H.
  • Third highest hardware priority.
  • Detects low levels or falling edges.

Timer 1 Interrupt (TF1)

  • Triggered by Timer 1 overflow.
  • Vector address is 001BH.
  • Fourth highest hardware priority.
  • Clears TF1 flag automatically.

Serial Port Interrupt (RI/TI)

  • Triggered by data transmission or reception.
  • Vector address is 0023H.
  • Lowest default hardware priority.
  • Requires manual software flag clearance.

Important Configuration Registers

  • IE (Interrupt Enable): Activates or deactivates individual interrupts.
  • IP (Interrupt Priority): Changes default priority levels.
  • TCON (Timer Control): Selects edge or level triggering.
8051 Interrupt Control Registers

8051 Microcontroller Interrupt Control Registers

IE: Interrupt Enable Register (Address: A8H)

Manages individual interrupt activation.

  • Bit 7 EA Global interrupt enable bit.
  • Bit 6 - Reserved for future use.
  • Bit 5 ET2 Timer 2 enable bit.
  • Bit 4 ES Serial port enable bit.
  • Bit 3 ET1 Timer 1 enable bit.
  • Bit 2 EX1 External interrupt 1 enable bit.
  • Bit 1 ET0 Timer 0 enable bit.
  • Bit 0 EX0 External interrupt 0 enable bit.

IP: Interrupt Priority Register (Address: B8H)

Sets priority levels for each interrupt.

  • Bit 7 - Reserved for future use.
  • Bit 6 - Reserved for future use.
  • Bit 5 PT2 Timer 2 priority bit.
  • Bit 4 PS Serial port priority bit.
  • Bit 3 PT1 Timer 1 priority bit.
  • Bit 2 PX1 External interrupt 1 priority bit.
  • Bit 1 PT0 Timer 0 priority bit.
  • Bit 0 PX0 External interrupt 0 priority bit.

TCON: Timer Control Register (Address: 88H)

Configures external interrupt triggering flags.

  • Bit 3 IE1 External 1 edge flag bit.
  • Bit 2 IT1 External 1 trigger select bit.
  • Bit 1 IE0 External 0 edge flag bit.
  • Bit 0 IT0 External 0 trigger select bit.

SCON: Serial Control Register (Address: 98H)

Contains hardware serial interrupt flags.

  • Bit 1 TI Transmit interrupt flag bit.
  • Bit 0 RI Receive interrupt flag bit.

8051 Microcontroller Timers and Counters

The 8051 microcontroller contains two 16-bit hardware blocks: Timer 0 and Timer 1.

Primary Functions

  • Timer Mode Generates accurate internal time delays.
  • Counter Mode Counts external electronic pulses or events.

Register Structure

  • Timer 0 Split into TH0 (High Byte) and TL0 (Low Byte).
  • Timer 1 Split into TH1 (High Byte) and TL1 (Low Byte).
  • Range Each register pair counts from 0000H to FFFFH.

Associated Hardware Pins

  • P3.4 (T0) External clock input for Timer 0.
  • P3.5 (T1) External clock input for Timer 1.

Control Registers

  • TMOD Timer Mode Register. Sets the mode of operation (Modes 0-3).
  • TCON Timer Control Register. Starts, stops, and monitors overflows.

How They Work

Timer Operation

  • The system clock drives the internal register.
  • The register increments once every machine cycle.
  • One machine cycle equals 12 crystal oscillator pulses.

Counter Operation

  • An external pin drives the internal register.
  • The register increments when a falling edge occurs.
  • The microcontroller samples the external pin every cycle.
